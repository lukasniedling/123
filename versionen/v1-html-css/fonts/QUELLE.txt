Fonts in this folder - where they come from  [V1]

Downloaded once on 2026-09-28 from the npm packages of Fontsource via
cdn.jsdelivr.net. The website loads them only from this folder (css/style.css,
section 1); no request goes to Google Fonts or any CDN when a page is opened.
