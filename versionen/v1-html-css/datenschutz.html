Das Wichtigste in Kürze

  • Keine Werbung, keine Statistik- oder Tracking-Dienste, keine Cookies.
  • Schriften, Fotos und der Lageplan liegen in unserem eigenen Ordner. Es entsteht keine Verbindung zu Google Fonts oder anderen fremden Diensten.
  • Einzige Ausnahme: die eingebettete OpenStreetMap-Karte auf der Seite Ort vorschlagen.

Was in deinem Browser passiert

In dieser Version laufen auf unseren Seiten keine eigenen Skripte (JavaScript). Wir speichern nichts in deinem Browser. Ein Link wie quadrate.html#q-G1 springt nur zu einer Stelle der Seite; dabei wird nichts übertragen.

OpenStreetMap-Karte auf „Ort vorschlagen“

Auf der Seite Ort vorschlagen ist eine Karte von OpenStreetMap eingebettet (iframe). Sobald sie angezeigt wird, lädt dein Browser sie direkt von den Servern der OpenStreetMap Foundation und übermittelt dabei deine IP-Adresse. Mehr dazu in der Datenschutzerklärung der OpenStreetMap Foundation (englisch).

Formular

Das Formular auf Ort vorschlagen verschickt in dieser Version noch nichts und speichert nichts. Der Versand folgt in einer späteren Version; dann ergänzen wir hier, welche Angaben wir speichern und wann wir sie löschen.
