Die Quadrate auf einen Blick

Die Mannheimer Innenstadt besteht aus 144 Quadraten, dazu kommen die Teilblöcke M3a und M4a. Klick auf ein Quadrat: Im Verzeichnis siehst du, wie viele Orte es dort zum Essen, Trinken, für Kultur und zum Shoppen gibt, und was das Quadrat besonders macht.

Tipp: Die Karte lässt sich seitlich verschieben.
